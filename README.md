# Mathe am PKG

Endlosschleife für das Display im Matheraum am Tag der offenen Tür des Paul-Klee-Gymnasiums Overath. Je Jahrgang von Klasse 5 bis Q2 zeigt ein kurzer 3D-Film ein Thema aus dem schulinternen Lehrplan, dazu stehen die Themen des Jahrgangs.

Bedienung: Klick oder F für Vollbild, Pfeiltasten für die nächste oder vorige Szene, Leertaste für Pause. Mit `?einfach` läuft die Seite ohne Leuchteffekt auf schwächeren Rechnern.

Die Datei `index.html` enthält alles (Three.js r169, MIT-Lizenz, und die Schriften Archivo und IBM Plex Mono, SIL Open Font License) und läuft auch ohne Internet.
